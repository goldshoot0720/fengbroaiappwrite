# 鋒兄試用／首購

入口：**鋒兄管理 → 試用/首購**。沿用訂閱／食品的 Appwrite CRUD 流程，使用獨立的 `trialpurchase` Table，不複製或修改舊資料。

## 第一次使用

在「鋒兄設定」確認 Appwrite 連線，找到 `trialpurchase` 並按「建立」。若表已存在但缺欄位，按「補齊欄位」。新表初次建立不開放公開讀寫，仍透過既有 Next.js API 與使用者設定的 API key 存取。API key 須有資料表／欄位建立及文件讀寫的相應權限。

初始化會等待欄位就緒才回報完成；重複操作只補缺少的欄位，保留原資料。若 Appwrite 尚在處理欄位，可稍後重試；若既有欄位型別不正確，需在 Appwrite 中檢查，程式不會為了修正型別刪掉資料表。

## 服務與帳號

一筆紀錄代表「某服務的一個帳號」，各自有日期、價格與狀態。相同服務名稱（忽略前後空白及英文字母大小寫）會自動歸成一組；點服務名稱可展開／收合帳號。沒有 25 或 33 筆上限，API 會分頁讀取所有資料。

- 「新增紀錄」可建立新服務的第一個帳號；服務右側「新增帳號」會預填服務名稱。
- 每個帳號旁的編輯按鈕可修改全部欄位。變更服務名稱會把這筆帳號移到對應服務群組。
- 刪除先顯示服務與帳號的確認對話框，預設焦點在「取消」。只有按「確認刪除」才刪除單筆紀錄；刪除不能復原，其他帳號不受影響。
- 搜尋涵蓋服務、帳號與備註；可篩選「尚未試用」或「未首購」。「待處理帳號」計算尚未試用或未首購的帳號聯集，不重複計數。
- 可匯出／匯入 `.csv`。匯出含目前全部帳號；匯入以「服務名稱 + 帳號」對應（忽略大小寫與前後空白），相同則更新、否則新增。CSV 裡沒有的紀錄不會被刪除。有任何格式錯誤時不會寫入。

## 欄位

| 畫面欄位 | Appwrite 欄位 | 規則 |
|---|---|---|
| 服務名稱 | `name` | 必填，最多 100 字元 |
| 試用／首購／到期日（扣款日） | `eventDate` | 選填；依此帳號目前階段記錄試用、首購或到期／扣款日，清空會移除日期 |
| 首購價格 | `firstPurchasePrice` | NT$，0 以上整數，預設 0 |
| 非首購價格 | `regularPrice` | NT$，0 以上整數，預設 0 |
| 帳號 | `account` | 最多 200 字元，可填 Email、使用者名稱或辨識名稱 |
| 備註 | `note` | 最多 3337 字元 |
| 試用狀態 | `trialStatus` | `untried` 尚未試用（預設）／`tried` 已試用 |
| 首購狀態 | `purchaseStatus` | `not_purchased` 未首購（預設）／`purchased` 已首購／`unavailable` 無提供首購 |

日期為日期型資料，不會由這個模組自動執行扣款、試用、購買或到期通知。狀態均由使用者維護。

## CSV

檔案以 UTF-8（含 BOM）儲存，方便 Excel 開啟。表頭可用英文欄位名或中文別名。

| 欄位 | 別名 | 說明 |
|---|---|---|
| name | 服務名稱、服務 | 必填，最多 100 字元 |
| eventDate | 試用／首購／到期日（扣款日）、日期、到期日、扣款日 | `YYYY-MM-DD` 或 `YYYY/MM/DD`；空白代表未設定 |
| firstPurchasePrice | 首購價格 | 0 以上整數，空白視為 0 |
| regularPrice | 非首購價格、一般價格 | 0 以上整數，空白視為 0 |
| account | 帳號 | 最多 200 字元 |
| note | 備註 | 最多 3337 字元 |
| trialStatus | 試用狀態 | `untried`／尚未試用（預設）、`tried`／已試用 |
| purchaseStatus | 首購狀態 | `not_purchased`／未首購（預設）、`purchased`／已首購、`unavailable`／無提供首購 |

匯出使用英文表頭與狀態代碼，再匯入可完整還原。空白檔只含表頭時可當範本，但不能直接匯入。

## API 與資料保護

`GET/POST /api/trial-purchase`；`PUT/DELETE /api/trial-purchase/[id]`。PUT 提交編輯表單的完整內容。錯誤時表單保留供修正，不會顯示成功；缺少欄位會阻止寫入，不會默默丟棄欄位。

資料只存於目前掛載的頁面記憶體，不放進共用 CRUD 快取；API 回應採 `private, no-store`。切換 Appwrite 設定會清除目前清單與未完成表單再重新載入。
