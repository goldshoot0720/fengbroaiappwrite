# 鋒兄首頁 (Home)

## 功能概述

鋒兄首頁是系統的入口點，為使用者提供整個管理系統的即時概覽與快速導航。原先獨立的「鋒兄儀表」已併入同一頁，可在「精簡」與「完整儀表」之間切換。

## 主要特點

- **系統標題**：顯示「鋒兄資訊管理系統」品牌標識與版本資訊。
- **快速入口**：跳到日常工作台、工具與子工具（完整清單見 [INDEX.md](./INDEX.md)）。
- **精簡／完整儀表**：同一頁切換待辦焦點與跨模組統計、媒體流量等完整資訊。
- **記憶上次選單**：離開網站時記住目前選單，下次回來沿用（本機 localStorage）。
- **動態顯示**：根據系統狀態動態更新提示資訊。
- **響應式佈局**：自動適應桌面、平板與手機裝置。

## 技術規格

- **元件路徑**：`app/page.tsx`
- **佈局元件**：`components/layout/DashboardLayout.tsx`
- **導航方式**：透過 `currentModule` 狀態切換動態元件渲染；`home`／`dashboard` 皆指向同一合併頁。
