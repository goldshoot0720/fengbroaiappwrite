# 鋒兄購物清單

入口：**鋒兄管理 → 購物清單**。記錄「想買的商品 × 一次預定購買」，沿用試用／首購與額度的管理 Table CRUD 流程，使用獨立的 `shoppinglist` Table。

## 第一次使用

在「鋒兄設定」確認 Appwrite 連線，找到 `shoppinglist` 並按「建立」。若表已存在但缺欄位，按「補齊欄位」。新表初次建立不開放公開讀寫，仍透過既有 Next.js API 與使用者設定的 API key 存取。

初始化會等待欄位就緒才回報完成；重複操作只補缺少的欄位，保留原資料。

## 使用方式

- 「新增商品」可建立新項目；每列「複製」會預填欄位供確認後新增。
- 編輯可修改全部欄位；「刪除」先顯示確認對話框（預設焦點在「取消」），按「確認刪除」才刪除單筆，無法復原。
- 搜尋涵蓋購物名稱、商店、取貨方式、帳號與備註；可篩選「3 天內要買」「今天要買」「已過購買日」「未設定日期」。
- 桌機顯示表格、手機顯示卡片。價格欄位顯示台幣換算與外幣原價（匯率為概估）；數量 × 單價另顯示小計。
- 可匯出／匯入 `.csv`。匯入以「購物名稱」對應（忽略大小寫與前後空白），相同則更新、否則新增；CSV 裡沒有的紀錄不會被刪除。有任何格式錯誤時不會寫入。

## 到期提醒

有「預定購買日」的項目會在到期前 3 天進入提醒窗口，每天通知一次，到期當天（剩 0 天）也算；已超過購買日不重複追蹤。提醒只在本機瀏覽器（完整儀表）顯示與通知，不會自動下單。

## 欄位

| 畫面欄位 | Appwrite 欄位 | 規則 |
|---|---|---|
| 購物名稱 | `name` | 必填，最多 100 字元 |
| 預定購買日 | `plannedDate` | 選填；決定到期提醒窗口 |
| 預定價格 | `price` | 0 以上整數，預設 0 |
| 幣別 | `currency` | `TWD`（預設）／`USD`／`JPY`／`CNY` |
| 預定數量 | `quantity` | 1 以上整數，預設 1 |
| 預定商店 | `shop` | 最多 100 字元，可從既有商店快速選取 |
| 預定取貨方式 | `pickupMethod` | 選填自由文字；常用建議：取貨付款、宅配、超商取貨、面交 |
| 帳號 | `account` | 最多 200 字元 |
| 備註 | `note` | 最多 3337 字元 |

## CSV

檔案以 UTF-8（含 BOM）儲存，方便 Excel 開啟。表頭可用英文欄位名或中文別名。

| 欄位 | 別名 | 說明 |
|---|---|---|
| name | 購物名稱、商品名稱、名稱 | 必填，最多 100 字元 |
| plannedDate | 預定購買日、購買日、預定日期 | `YYYY-MM-DD` 或 `YYYY/MM/DD`；空白代表未設定 |
| price | 預定價格、價格、金額 | 0 以上整數，空白視為 0 |
| currency | 幣別、幣種、貨幣 | 台幣／TWD（預設）、美元／USD、日圓／JPY、人民幣／CNY |
| quantity | 預定數量、數量 | 1 以上整數，空白視為 1 |
| shop | 預定商店、商店、店家 | 最多 100 字元 |
| pickupMethod | 預定取貨方式、取貨方式、取貨 | 自由文字；取貨付款、宅配 |
| account | 帳號 | 最多 200 字元 |
| note | 備註 | 最多 3337 字元 |

匯出使用英文表頭，再匯入可完整還原。

## API 與資料保護

`GET/POST /api/shopping-list`；`PUT/DELETE /api/shopping-list/[id]`。PUT 提交編輯表單的完整內容。缺少欄位會阻止寫入，不會默默丟棄欄位。

資料只存於目前掛載的頁面記憶體；切換 Appwrite 設定會清除目前清單與未完成表單再重新載入。
