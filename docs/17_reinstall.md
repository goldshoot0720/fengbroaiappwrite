# 鋒兄重灌

入口：**鋒兄管理 → 重灌**。整理 Windows／Mac 重灌時需要重新安裝的軟體，使用獨立的 `reinstall` Table，不修改既有訂閱／食品資料。

## 第一次使用

在「鋒兄設定」確認 Appwrite 連線，找到 `reinstall` 按「建立」。若缺少欄位，可按「補齊欄位」。初始化只新增／補齊，保留已有紀錄，欄位就緒後才回報完成。建立新表時不授予公開讀寫權限，存取沿用既有伺服器 API key 流程。

## 操作

- 按「新增軟體」填寫安裝資訊；每筆紀錄可選 Windows 或 Mac，跨平台軟體可分別建立兩筆。
- 可搜尋服務名稱、網站與備註，並依系統、試用／免費／付費軟體，以及是否訂閱制篩選。
- 付費序號在清單及新增／編輯表單都預設隱藏，按眼睛按鈕才顯示。若這筆紀錄設了「查看密碼」，清單需先輸入正確密碼才顯示序號。重新整理、切換頁面或切換 Appwrite 帳戶後會再次隱藏；長序號可換行顯示完整內容。
- 授權方式改為「無序號」後，儲存時會清除舊序號與查看密碼；「付費序號」與「查看密碼」也可先留空待補。
- 每筆可編輯全部欄位。刪除對話框會顯示軟體名稱及系統，預設聚焦「取消」；只有「確認刪除」才會刪除該筆，不影響其他軟體。
- 網站只接受完整 `http://` 或 `https://` 網址，並以新分頁開啟。
- 可匯出／匯入 `.csv`。匯出含目前全部軟體（含付費序號與查看密碼）；匯入以「服務名稱 + 使用系統」對應（名稱忽略大小寫與前後空白），相同則更新、否則新增。CSV 裡沒有的紀錄不會被刪除。有任何格式錯誤時不會寫入。

## 欄位

| 畫面欄位 | Appwrite 欄位 | 規則 |
|---|---|---|
| 服務名稱 | `name` | 必填，最多 100 字元 |
| 使用系統 | `system` | `win` Windows（預設）／`mac` Mac |
| 軟體類型 | `softwareType` | `trial` 試用／`free` 免費（預設）／`paid` 付費 |
| 訂閱制軟體 | `subscriptionSoftware` | 是否為訂閱制，預設否 |
| 訂閱週期 | `subscriptionPeriod` | 訂閱制時為 `?年` 或 `?月`（例如 `1年`、`3月`）；非訂閱制時清空 |
| 訂閱費用 | `subscriptionPrice` | 0 以上整數；非訂閱制時為 0 |
| 訂閱費用幣別 | `subscriptionCurrency` | `TWD` 台幣（預設）／`USD` 美元／`JPY` 日圓／`CNY` 人民幣；非訂閱制時回到台幣 |
| 授權方式 | `licenseType` | `none` 無序號（預設）／`paid_serial` 付費序號 |
| 付費序號 | `serial` | 最多 500 字元；無序號時清空 |
| 查看密碼 | `viewPassword` | 選填，最多 100 字元；清單顯示付費序號時需輸入。無序號時清空 |
| 軟體網站 | `site` | 選填完整 HTTP(S) 網址；清空會移除網址 |
| 備註 | `note` | 最多 3337 字元 |

軟體類型、訂閱制與授權方式是獨立欄位：例如付費軟體也可能是訂閱制、或使用帳號登入而不提供序號。本模組只管理資料，不會下載、安裝或啟用軟體。既有資料表請到「鋒兄設定」按「補齊欄位」新增訂閱相關欄位。

## 序號安全範圍

遮罩與查看密碼都是防止畫面旁觀的介面措施，**不是加密保管庫**。查看密碼與序號一併存在 Appwrite，有資料／API key 存取權限的人仍可讀取，瀏覽器載入清單時也會收到這兩個欄位。請妥善保管 API key 並使用可信任的裝置。既有資料表請到「鋒兄設定」按「補齊欄位」新增缺少的欄位（含 `viewPassword` 與訂閱欄位）。

新表不設公開權限，API 回應使用 `private, no-store`，序號不進共用 CRUD 快取。已存在資料表的權限不會被自動改寫，應自行檢查 Appwrite 權限。

## CSV

檔案以 UTF-8（含 BOM）儲存，方便 Excel 開啟。表頭可用英文欄位名或中文別名。匯出含付費序號與查看密碼，請妥善保管。

| 欄位 | 別名 | 說明 |
|---|---|---|
| name | 服務名稱、軟體名稱 | 必填，最多 100 字元 |
| system | 使用系統、系統 | `win`／Windows（預設）、`mac`／Mac |
| softwareType | 軟體類型 | `trial`／試用、`free`／免費（預設）、`paid`／付費 |
| licenseType | 授權方式 | `none`／無序號（預設）、`paid_serial`／付費序號 |
| serial | 付費序號、序號 | 最多 500 字元；無序號時忽略 |
| viewPassword | 查看密碼 | 最多 100 字元；無序號時忽略 |
| subscriptionSoftware | 訂閱制軟體、訂閱制 | `true`／是、`false`／否（預設） |
| subscriptionPeriod | 訂閱週期、週期 | 訂閱制時為 `?年` 或 `?月`；空白視為 1 月 |
| subscriptionPrice | 訂閱費用、費用 | 0 以上整數 |
| subscriptionCurrency | 訂閱費用幣別、幣別 | `TWD`／台幣（預設）、`USD`／美元、`JPY`／日圓、`CNY`／人民幣 |
| site | 軟體網站、網站 | 完整 `http://` 或 `https://` 網址 |
| note | 備註 | 最多 3337 字元 |

匯出使用英文表頭與狀態代碼，再匯入可完整還原。空白檔只含表頭時可當範本，但不能直接匯入。

## API

`GET/POST /api/reinstall`；`PUT/DELETE /api/reinstall/[id]`。PUT 提交完整編輯表單；欄位驗證失敗會保留表單供修正。不存在的資料表、未就緒欄位與權限錯誤會分別回報，不會以缺表掩蓋權限錯誤。
