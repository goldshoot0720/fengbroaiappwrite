# 鋒兄 Udemy

入口：**鋒兄管理 → Udemy**。記錄 Udemy 課程、講師、程式語言／框架／技術與觀看進度，使用獨立的 `udemy` Table，沿用購物清單的管理 Table CRUD 流程。

## 建立 Table

在「鋒兄設定」確認 Appwrite 連線，找到 `udemy` 並按「建立」。若表已存在但缺欄位，按「補齊欄位」；初始化不會刪除既有資料。新表不開放公開讀寫，仍透過 Next.js API（`/api/udemy`）與使用者設定的 API key 存取。

## 頁面功能

- 上方統計：課程數、已經完整收看門數、已觀看堂數／課程總堂數、整體已經觀看比重。
- **依此分類**：講師、課程名稱、程式語言、框架、技術名稱、收看狀態（課程已經完整收看／課程尚未完整收看）。每個群組標題顯示門數、群組合計堂數與觀看比重；未填欄位的課程歸到「未填…」群組並排在最後。
- 程式語言／框架／技術名稱可填多個值（以「,」或「、」分隔），同一門課會出現在每個值的群組。
- 收看狀態篩選：全部／已完整收看／尚未完整收看；搜尋涵蓋課程名稱、講師、程式語言、框架與技術名稱。
- 每門課顯示「已觀看堂數 / 課程總堂數」與已經觀看比重進度條。已完整收看的課程一律算 100%；未填總堂數算 0%。
- 表單中已觀看堂數到達總堂數會自動勾選「課程已經完整收看」，勾選時已觀看堂數會補滿到總堂數。
- 支援新增、編輯、複製、刪除、多選批次刪除，以及 CSV 匯出／匯入（以課程名稱對應，忽略大小寫與前後空白，相同則更新、否則新增）。鋒兄設定的一鍵備份也包含 `udemy.csv`。

## 欄位

| 欄位 | Appwrite key | 型別 | 規則 |
|------|-------------|------|------|
| 課程名稱 | `name` | string(200) | 必填 |
| 講師名稱 | `instructor` | string(200) | |
| 程式語言 | `language` | string(200) | 多值以「,」「、」分隔 |
| 框架 | `framework` | string(200) | 多值以「,」「、」分隔 |
| 技術名稱 | `technology` | string(200) | 多值以「,」「、」分隔 |
| 已觀看堂數 | `watchedLectures` | integer | 0 以上；不可超過課程總堂數 |
| 課程總堂數 | `totalLectures` | integer | 0 以上 |
| 課程上次更新時間 | `courseUpdatedAt` | datetime | 可留空 |
| 課程總時長（小時） | `totalHours` | float | 0 以上，取到小數第二位 |
| 課程已經完整收看 | `completed` | boolean | 預設 false |

## CSV

表頭可用英文 key 或中文名稱（例如「課程名稱」「講師名稱」「已觀看堂數」「課程上次更新時間」「課程總時長小時」「課程已經完整收看」）。日期接受 `2025-08-01`、`2025/8/1`，或只有年月的 `2025/8`（補成當月 1 日，對應 Udemy 的「上次更新 2025/8」）。完整收看欄接受 `true/false`、`是/否`、`1/0`。有任何格式錯誤時不會寫入。
