# 鋒兄關於 (About)

## 功能概述

顯示系統版本資訊、技術架構、開發團隊與功能模組總覽，提供五個分頁查看詳細資訊。

## 主要特點

- **公司簡介**：鋒兄塗哥公關資訊有限公司介紹、團隊成員資料。
- **系統架構**：技術架構圖與說明。
- **功能模組**：15 個功能模組的總覽說明。
- **技術文件**：開發者技術規格文件。
- **使用手冊**：使用者操作指南。

## 分頁結構

| # | 分頁名稱 | 內容 |
|---|---------|------|
| 1 | 公司簡介 | 公司 Logo、名稱、團隊成員 (鋒兄、塗哥)、服務特色 |
| 2 | 系統架構 | 技術架構總覽、前後端架構圖 |
| 3 | 功能模組 | 15 個模組的功能說明 |
| 4 | 技術文件 | TypeScript 類型、API 端點、資料庫 Schema |
| 5 | 使用手冊 | 操作說明、常見問題 |
