## 💻 核心產品：鋒兄資訊系統

**鋒兄AI Appwrite 管理系統** 是公司的旗艦產品，整合了 15 大功能模組：

### 系統架構

```

│  │ (15 個)   │  │ (51 個)   │  │ (17 個)         │  │
│  └──────────┘  └──────────┘  └──────────────────┘  │
│                       │                              │
│              ┌────────┴────────┐                     │
│              │  IndexedDB 快取  │                     │
│              │  (離線瀏覽支援)   │                    │
│              └─────────────────┘                     │
└────────────────────────┬───────────────────────────┘

┌────────────────────────┴───────────────────────────┐
```

### 核心特色

#### 🎨 使用者體驗

- ✅ **三種主題模式**: 亮色 / 暗色 / 跟隨系統
- ✅ **響應式設計**: 支援手機、平板、桌面
- ✅ **離線功能**: 媒體快取與離線瀏覽
- ✅ **PWA 支援**: 可安裝為手機 App

#### 📊 數據管理

- ✅ **智慧統計**: 即時數據分析與視覺化
- ✅ **自動提醒**: 到期通知與桌面推播
- ✅ **多幣別支援**: 自動匯率換算 (TWD/USD/EUR/JPY/CNY/HKD)
- ✅ **批次操作**: CSV/ZIP 匯入匯出

#### 🚀 技術優勢

- ✅ **AI 自動化**: 智慧化資料處理
- ✅ **雲端整合**: Appwrite 後端服務
- ✅ **動態配置**: 免重新部署即可切換帳號
- ✅ **高效快取**: IndexedDB 離線儲存 (500MB/類型)
- ✅ **串流播放**: HTTP Range 請求支援

#### 🔒 安全與穩定

- ✅ **權限管理**: API Key 認證機制
- ✅ **資料備份**: Appwrite 雲端備份
- ✅ **錯誤處理**: 完整的錯誤提示與復原機制
- ✅ **快取控制**: 自動清除超限快取
