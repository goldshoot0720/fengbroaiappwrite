# 鋒兄儀表 (Dashboard)

## 功能概述

提供全系統的數據統計概覽，彙整食品、訂閱、銀行、多媒體等各模組的關鍵指標，並提供到期提醒與瀏覽器通知功能。

## 主要特點

- **統計卡片**：展示各模組的總量與關鍵數值。
- **到期警示**：標示即將到期或已過期的食品與訂閱。
- **財務概覽**：統計訂閱費用的年度/月度支出。
- **多媒體統計**：顯示各類媒體的數量與儲存空間。
- **瀏覽器通知**：每日自動檢查到期狀況並推播通知。

## 統計區塊

### 食品統計

| 指標 | 說明 | 顏色 |
|------|------|------|
| 食品總數 | 庫存中的食品項目總數 | 藍色 |
| 正常項目 | 距到期日超過 7 天 | 綠色 |
| 7 天內到期 | 即將過期的食品 | 黃色 |
| 30 天內到期 | 較近期到期的食品 | 橘色 |
| 已過期 | 已超過到期日 | 紅色 |

### 訂閱統計

| 指標 | 說明 | 顏色 |
|------|------|------|
| 訂閱總數 | 所有追蹤中的訂閱 | 藍色 |
| 3 天內到期 | 即將需要續費 | 紅色 |
| 7 天內到期 | 近期需注意 | 橘色 |
| 已逾期 | 已超過續費日期 | 紅色 |

### 財務概覽

| 指標 | 說明 |
|------|------|
| 年費總計 | 所有訂閱的年度費用（換算台幣） |
| 月費總計 | 所有訂閱的月度費用 |
| 下月預估費 | 下個月的預估支出 |
| 銀行帳戶數 | 已登記的銀行帳戶數量 |
| 總存款 | 所有銀行帳戶的存款總額 |

### 多媒體儲存

| 媒體類型 | 統計內容 |
|----------|---------|
| 圖片 | 數量與佔用空間 |
| 影片 | 數量與佔用空間 |
| 音樂 | 數量與佔用空間 |
| 文件 | 數量與佔用空間 |
| 播客 | 數量與佔用空間 |

儲存空間進度條顏色：綠色 (<50%)、橘色 (50-80%)、紅色 (>80%)

## 到期提醒機制

| 門檻常數 | 值 | 說明 |
|----------|---|------|
| FOOD_EXPIRING_SOON | 7 天 | 食品即將到期警示 |
| FOOD_EXPIRING_WARNING | 30 天 | 食品到期預警 |
| SUBSCRIPTION_URGENT | 3 天 | 訂閱緊急提醒 |
| SUBSCRIPTION_WARNING | 7 天 | 訂閱到期預警 |

- 系統每日自動檢查食品與訂閱的到期狀況
- 支援瀏覽器桌面通知（每日提醒一次，不重複打擾）
- 訂閱 3 天內到期時觸發瀏覽器推播通知

## 技術規格

- **元件路徑**：`components/modules/EnhancedDashboard.tsx`
- **統計類型定義**：`types/index.ts` → `DashboardStats`
- **門檻常數**：`lib/constants.ts` → `DATE_THRESHOLDS`
